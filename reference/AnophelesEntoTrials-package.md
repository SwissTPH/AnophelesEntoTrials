# AnophelesEntoTrials: Estimate the Impact of Malaria Vector Control Interventions Based on Entomological Data

The AnophelesEntoTrials R package provides a platform to estimate the
impact of malaria vector control interventions based on entomological
data using MCMC models. It supports fitting Bayesian models to
Entomological Hut Trial (EHT) data to estimate intervention efficacy
parameters including reduction in host availability, pre-prandial
killing, and post-prandial killing.
